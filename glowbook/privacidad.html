Privacy Policy – Glowbook Uploader

Last updated: November 2, 2026

Glowbook Uploader is a private tool operated by Luis Manuel Ahumada, owner of the YouTube channel Glowbook Bible Stories (UCGezXqYJPkWo0uqMEmDK8cQ). It is used only by the channel owner.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

What data is accessed

  • Only the owner's own channel, through the OAuth scopes youtube.upload, youtube and youtube.force-ssl.
  • Endpoints used: videos.insert, thumbnails.set, captions.insert, channels.list (to confirm the destination channel) and videos.list.
  • No data about viewers, other users or other channels is read, collected, stored or shared.
  • The content is made for kids; the tool performs no collection of any personal information from children.

Storage and security

The OAuth token is stored only on the owner's private server with restricted file permissions. It is never shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

The tool stores no user data from YouTube. It keeps only a local log of the owner's own uploads (video IDs and scheduled dates). The OAuth token can be deleted at any time by removing it from the server; once access is revoked, any stored API data is deleted within 7 days. Requests to delete data can be sent to lemotsur@gmail.com.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions or via the Google security settings page.
