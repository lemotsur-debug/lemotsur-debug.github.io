Privacy Policy — Noche en Negro Uploader

Last updated: September 16, 2026

What this application is

Noche en Negro Uploader is a private, single-user automation owned and operated by the owner of the YouTube channel "Noche en Negro" (channel ID UCnqNMJUosyha5wr-NxRDX1Q). It uploads the channel owner's own original videos to that same channel on a daily schedule. It is not a public product and has no other users.

Data accessed

The application uses the YouTube Data API v3 only to: upload videos (videos.insert), set custom thumbnails (thumbnails.set) and read back the status of its own uploads (videos.list). It does not read, search, download or store data about other channels, videos or users.

Authorization and storage

Authorization is granted once by the channel owner through Google OAuth 2.0 (scopes youtube.upload and youtube). The resulting token is stored only on the owner's private server on a local network, with restricted file permissions. Video files, metadata and logs remain on that server.

Sharing

No data is sold, shared with or transferred to third parties. The only optional outbound message besides the YouTube API is a private notification to the channel owner reporting the result of each run; it contains no user data.

Google API Services

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also complies with the YouTube API Services Terms of Service. By using it, the channel owner is also bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Stored tokens are deleted when access is revoked or the application is retired.
