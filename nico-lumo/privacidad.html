Privacy Policy — Canal Nico y Lumo

Last updated: September 19, 2026

What this application is

Canal Nico y Lumo is a private, single-user automation owned and operated by the owner of the YouTube channel with ID UCzSPFPTzoOOw2obfd2etotw. It uploads and schedules the channel owner's own original videos, sets their thumbnails, organizes them into the channel's own playlists and runs scheduled live streams of the owner's own content on that same channel. It is not a public product and has no other users.

Data accessed

The application uses the YouTube Data API v3 only to: upload and update videos (videos.insert, videos.update), set custom thumbnails (thumbnails.set), manage the channel's own playlists (playlistItems), create and control the channel's own live broadcasts and streams (liveBroadcasts, liveStreams) and read back the status of its own content (videos.list, playlistItems.list). It does not read, search, download or store data about other channels, videos or users.

Authorization and storage

Authorization is granted once by the channel owner through Google OAuth 2.0 (scopes youtube.upload, youtube and youtube.force-ssl). The resulting token is stored only on the owner's private server on a local network, with restricted file permissions. Video files, metadata and logs remain on that server.

Sharing

No data is sold, shared with or transferred to third parties. The only optional outbound message besides the YouTube API is a private notification to the channel owner reporting the result of each run; it contains no user data.

Children's privacy

The channel's content is set as "made for kids". This application does not collect any information from viewers, children or anyone else; it only publishes the owner's content.

Google API Services

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also complies with the YouTube API Services Terms of Service. By using it, the channel owner is also bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Stored tokens are deleted when access is revoked or the application is retired.
